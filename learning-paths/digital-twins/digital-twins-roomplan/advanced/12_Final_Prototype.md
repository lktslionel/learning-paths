## Final Checklist

### Core Product
- [ ] Multi-room scanning with continuous session
- [ ] Structure merging and USDZ export
- [ ] Interactive viewer with selection and dimensions
- [ ] Project save / load / delete
- [ ] Custom model support (or clear path to it)
- [ ] Share functionality

### Quality
- [ ] Graceful error handling
- [ ] Reasonable performance on device
- [ ] Clean navigation and empty states
- [ ] Basic accessibility

### Documentation
- [ ] README explaining how to build and run
- [ ] Short demo script or video
- [ ] Known limitations clearly stated
- [ ] Future roadmap ideas (multi-floor, industrial hybrid, cloud sync, etc.)

## Recommended Final Demo Flow
1. Create a new project
2. Scan 2–3 connected rooms
3. Merge and export
4. Open in interactive viewer
5. Select elements and show dimensions
6. Share the USDZ
