# Week 9 – Production Polish & Project Management (Practice)

**Time:** 4 hours  
**Type:** Practice  
**Goal:** Turn the prototype into something that feels production-ready.

---

## Schedule

| Block                | Duration | Activity |
|----------------------|----------|----------|
| Project Persistence  | 1 h 30 m | Save / load scans |
| UI/UX Polish         | 1 h 30 m | Navigation, empty states, errors |
| Sharing & Export     | 1 h      | Share sheet + quality options |

---

## Tasks

1. Implement local project storage (save CapturedStructure / USDZ + metadata).
2. Add a projects list screen (create, open, delete, rename).
3. Improve scanning UX (progress, guidance, cancel confirmation).
4. Add proper error states and recovery.
5. Polish export options (parametric vs model, quality settings).
6. Implement system share sheet for USDZ files.
7. Basic accessibility (VoiceOver labels, Dynamic Type where relevant).

---

## Success Criteria
- [ ] User can create multiple projects and return to them later
- [ ] App handles common failure cases gracefully
- [ ] UI feels coherent and intentional
- [ ] Export & share works reliably

---

## Deliverable
Polished multi-screen HomeTwin app with project management.
