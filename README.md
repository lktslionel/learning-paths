# learning-paths

Directory structure for organizing learning paths by theme, topic, and level:

```text
learning-paths/
  frontend/
    html-css/
    javascript/
    react/
  backend/
    api-design/
    nodejs/
    databases/
  data/
    sql/
    python-data/
    machine-learning/
  devops/
    linux/
    git-ci-cd/
    cloud/
  digital-twins/
    digital-twins-roomplan/
    digital-twins-computer-vision/
```

Each topic contains:

- `beginner/`
- `intermediate/`
- `advanced/`

Use each level folder to store learning path files for that specific progression stage.
